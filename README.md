## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Profile Export** | Export current Native Settings UI configuration as a named profile |
| **Profile Import** | Restore any saved profile to instantly reconfigure all mod settings |
| **Settings Browser** | Browse all Native Settings-registered mods and their options |
| **Diff View** | Compare two saved profiles to see what changed between them |
